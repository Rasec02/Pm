# Capturas de pantalla

Aquí van las **capturas reales** de la app ejecutándose en el emulador o en un
teléfono Android (no mockups). Nombres sugeridos:

| Archivo | Pantalla |
|---------|----------|
| `01-ordenes-abiertas.png` | Lista de órdenes abiertas con filtros y responsables |
| `02-detalle-orden.png` | Detalle de una orden con trabajos, repuestos y costo total |
| `03-tomar-orden.png` | Acción de tomar la orden (responsable único) |
| `04-inventario-stock-bajo.png` | Inventario con la alerta de stock bajo y el umbral |
| `05-historial-equipo.png` | Historial de reparaciones de un equipo |
| `06-historial-cliente.png` | Historial de un cliente con todos sus equipos |
| `07-carga-trabajo.png` | Carga de trabajo por técnico |

Cómo tomarlas:

- Emulador Android Studio: botón de cámara en la barra lateral.
- Teléfono: `Power + Volumen abajo`.
- Guárdalas en esta carpeta (`docs/screenshots/`) y enlázalas desde el README
  principal con `![Descripción](docs/screenshots/archivo.png)`.
